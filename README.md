# Servant - Documentation française

Bienvenue sur le dépôt français de **Servant: Sealbound Companions**.

Servant ajoute de rares compagnons humanoïdes à Minecraft. Libérez un prisonnier dans un avant-poste de pillards, recrutez-le avec un Sceau d'asservissement, équipez-le et confiez-lui un rôle. Il pourra vous suivre, garder une zone, travailler dans votre base ou devenir votre Assistant personnel.

Ce dépôt contient la **documentation française** du mod. Le code source et le développement principal se trouvent sur [Azashiin/Servant](https://github.com/Azashiin/Servant).
